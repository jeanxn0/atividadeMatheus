# 💻 Exercícios de C# — Vetores, Matrizes e Cadastro

> Coleção de atividades acadêmicas desenvolvidas em C# para praticar lógica de programação, vetores, matrizes e organização de dados.

## 📚 Conteúdo

| Pasta | Descrição |
|---|---|
| `listaVetor` | Exercícios com vetores, incluindo buscas, cálculos e manipulação de dados |
| `ListaMatriz` | Exercícios de leitura e processamento de matrizes |
| `CadastroBandas2025-main` | Aplicação de console para cadastro e gerenciamento de bandas |

## 🛠️ Tecnologias

- C#
- .NET
- Programação orientada a objetos
- Aplicações de console

## ▶️ Como executar

1. Clone este repositório.
2. Entre na pasta do exercício desejado.
3. Execute:

```bash
dotnet run
```

## 🎯 Objetivo

Registrar minha evolução em C# por meio de exercícios práticos realizados durante a graduação em Sistemas de Informação.
